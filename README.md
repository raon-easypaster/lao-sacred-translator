# Lao Sacred Language Translator (LSLT)
### 라오스 종교언어·왕실언어·현대일반언어 전문 번역 플랫폼

Lao Sacred Language Translator(LSLT)는 선교사, 성경 번역가, 신학 연구자 및 목회자를 위해 개발된 고성능 AI 번역 및 지식 데이터베이스 연구 플랫폼입니다. 현대 일반 라오어, 불교 종교어, 왕실 격식어(Rahasap), 그리고 기독교 신학어 간의 유기적인 교차 번역 및 RAG(검색 증강 생성) 기반 지식 관리 기능을 지원합니다.

---

## 🌟 주요 기능

1. **지식 베이스 업로더 (PDF & Markdown RAG)**
   * PDF, Word, EPUB, HTML 및 마크다운(.md) 문헌 업로드 지원.
   * 자동으로 텍스트 추출, 문단 분리(Chunking) 및 의미 기반 벡터 인덱싱 수행.
   * AI 문서 사전 프로필(요약, 신학적 의의, 인물/장소, 역사적 배경 분석) 생성.
2. **다중 문체 번역 스튜디오**
   * 일반 라오어 ↔ 종교 라오어 ↔ 왕실어 ↔ 한국어 상호 방향 번역.
   * 실시간 전문 용어 사전 매핑 및 유사 문헌 구절 추출(RAG) 주입.
   * 음성 입력(STT) 및 라오어 발음 출력(TTS) 지원.
3. **선교학 상황화 모드**
   * 불교 문화권(업보, 공덕, 해탈 등) 신자들이 오해하기 쉬운 표현 필터링 및 주의사항 제공.
   * 4가지 스타일 번역본 동시 제시 (직역본, 설교체 번역본, 현지인 친화형 번역본, 소그룹 교재용 번역본).
4. **평행 성경 연구 모드**
   * 성경 구절별 한국어, 현대 일반 라오어, 종교 라오어, 왕실 라오어 4단 평행 대조.
   * 단어별 원어 의미론 및 신학적 주석 분석 자료실.
5. **전문 사전 및 지식 그래프**
   * 기독교-불교 핵심 교리 단어 의미론적 비교 사전 관리.
   * SVG 기반 종교 핵심 개념 관계도 지식 그래프 시각화.
6. **검수 워크플로우 제어**
   * AI 번역 → 현지인 검수 → 선교사 검수 → 최종 승인 다단계 파이프라인 관리.

## 💾 설치 방법 (Installation)

### 1단계: 프로젝트 디렉토리로 이동
터미널을 열고 플랫폼이 구축된 폴더로 이동합니다.
```bash
cd /Users/galeb76/.gemini/antigravity/scratch/lao-sacred-translator
```

### 2단계: 백엔드(FastAPI) 설치 및 가상환경 구성
1. 백엔드 폴더로 이동하여 가상환경을 활성화합니다.
   ```bash
   cd backend
   python3 -m venv .venv
   source .venv/bin/activate
   ```
2. 필요 패키지를 설치합니다.
   ```bash
   pip install -r requirements.txt
   ```
3. `.env` 파일을 구성하여 API 키를 설정합니다. (비워둘 경우 사전 기반 오프라인 번역 모드로 구동)
   ```bash
   # backend/.env 파일 편집
   GEMINI_API_KEY=YOUR_GEMINI_API_KEY
   OPENAI_API_KEY=YOUR_OPENAI_API_KEY
   CLAUDE_API_KEY=YOUR_CLAUDE_API_KEY
   ```

### 3단계: 프론트엔드(Vite + React) 패키지 설치
1. 프론트엔드 폴더로 이동합니다.
   ```bash
   cd ../frontend
   ```
2. npm 의존성 패키지를 설치합니다.
   ```bash
   npm install
   ```

## 🚀 실행 및 사용 방법 (Usage)

시스템 구동을 위해 **백엔드 서버**와 **프론트엔드 서버**를 각각 실행해야 합니다.

### 1. 백엔드 API 서버 실행 (Port: 8000)
새로운 터미널 창을 열고 아래 명령어를 입력합니다.
```bash
cd /Users/galeb76/.gemini/antigravity/scratch/lao-sacred-translator/backend
.venv/bin/uvicorn main:app --reload --port 8000
```
* 서버가 시작되면 내부적으로 `lslt_database.db` 파일이 자동 생성되고 사전 데이터가 초기 세팅됩니다.

### 2. 프론트엔드 개발 서버 실행 (Port: 5173)
또 다른 터미널 창을 열고 아래 명령어를 입력합니다.
```bash
cd /Users/galeb76/.gemini/antigravity/scratch/lao-sacred-translator/frontend
npm run dev
```
* 실행이 완료되면 터미널에 나타나는 로컬 웹 주소(`http://localhost:5173`)를 클릭하여 브라우저로 접속합니다.

## 📖 플랫폼 사용 방법 가이드

### 1. RAG 지식 데이터베이스 구축하기 (PDF/Markdown 업로드)
1. 사이드바 메뉴에서 **[학습 문헌 센터]**를 클릭합니다.
2. **"신규 참고 문헌 업로드"** 카드에서 PDF 책이나 마크다운(`.md` 또는 `.txt`) 파일을 드래그하거나 선택합니다.
3. **[문헌 업로드 및 데이터 학습]**을 클릭하면 백엔드에서 문서를 파싱하고 문단별 벡터 데이터베이스 인덱싱 작업을 자동으로 진행합니다.
4. 등록 완료 후 **"학습 완료 문헌 데이터베이스"**에서 문서를 선택하면 요약문과 교리적 분석 결과를 조회할 수 있습니다.
5. 상단의 **"지식 베이스 의미론적 검색 (RAG Search)"**창에 찾고자 하는 신학 구절을 입력해 문서 내용들을 신속하게 검색할 수 있습니다.

### 2. 다각도 문체 번역 스튜디오 사용하기
1. 사이드바 메뉴에서 **[번역 스튜디오]**를 클릭합니다.
2. 상단 바에서 번역 방향(예: `한국어 → 라오스 종교어`)과 **[선교사 모드]** 등의 옵션을 고릅니다.
3. 원문 란에 번역할 텍스트를 입력하고 **[전문 번역 실행]**을 누릅니다.
   * **마이크 버튼**: 브라우저 음성 인식을 통해 음성으로 텍스트 입력(STT)이 가능합니다.
4. 우측 결과 창에 최종 번역문, 직역문, 의역문, 설교체 결과가 출력됩니다.
   * **[라오어 발음 (TTS)]** 버튼을 누르면 인공지능이 라오어 음성을 읽어줍니다.
   * **[MD / HTML / DOCX]** 단추로 분석 보고서 파일을 즉시 다운로드할 수 있습니다.
5. 하단 탭에서는 문장 내에 섞인 종교 어휘 해설, 상황화 경고, RAG 출처 문서 정보를 한눈에 비교 검토합니다.

### 3. 설교문 상황화 번역 & 분석하기
1. **[설교문 컨텍스츄얼]** 메뉴를 선택합니다.
2. 좌측 텍스트 상자에 작성하신 설교문 단락을 기재하고 번역 버튼을 누릅니다.
3. 우측에 **[설교체]**, **[현지인 친화형]**, **[직역본]**, **[소그룹 교재용]** 4개 버전의 번역이 동시 생성되어 예배 환경에 따라 선택하여 활용할 수 있습니다.
4. 하단의 분석창을 통해 불교 문화권 신자에게 부적절한 충돌 어휘 분석 결과 및 대체 은유 제안을 확인합니다.

### 4. 성경 주해 대조 및 용어 관리
* **[성경 연구 모드]**: 요한복음 또는 창세기 장절을 선택해 일반/종교/왕실어 성경 구절을 병렬로 비교하고 어휘 주해를 확인하며 보고서로 추출합니다.
* **[용어 사전 관리]**: 기독교-불교 개념 대조표 및 단어를 관리하고, 🕸️ 개념 관계도 지식 그래프 탭을 활용해 구원론 및 신론 어휘의 다이어그램 맵을 확인합니다.
* **[AI 모델 설정]**: Gemini/OpenAI/Claude 및 로컬 사전 번역 엔진 옵션을 변경하고 API 키를 입력할 수 있습니다.
